# 📊 Credit Card Case Study — SQL Analytics Project

### 🔍 Objective  
Analyze real credit card transaction patterns across India using SQL to uncover insights that help banks improve customer segmentation, spending analysis, and fraud detection.

---

## 📁 Folder Content  
This project folder contains **3 files**:

1. **Credit-card-transactions-India.csv**  
   → Raw dataset containing customer transactions.

2. **Structure before importing.sql**  
   → SQL schema creation file (tables + data types).

3. **Credit Card SQL Project.sql**  
   → Full analysis script containing 20+ queries used for business insights.

---

## 🛠️ Tools & Technologies  
- MySQL (SQL)  
- Excel  
- Power BI (visualization-ready output)

---

## 📌 Key Business Questions Solved  
- Which cities/states have the highest transaction volume?  
- Which transaction categories generate the most revenue?  
- Customer spending trends → gender, category, card type.  
- Monthly/weekly/festival season transaction analysis.  
- Fraud pattern detection and unusual transaction tracking.

---

## 📈 Insights Summary  
- Highest spending observed in **online purchases & travel**.  
- **Metro cities** dominated total transaction value.  
- **Weekend** transactions were consistently higher.  
- Credit **EMI categories** showed the largest ticket sizes.  
- Detected spikes that may indicate **fraudulent activity**.
